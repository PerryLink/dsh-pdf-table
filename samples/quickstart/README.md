# quickstart sample

- `input/table-demo.pdf` — synthetic 1-page PDF generated by `node scripts/make-sample.mjs`
  (pdf-lib 1.17.1). It contains a 4-column × 3-row table and one prose line. The prose line
  is deliberately skipped by `pdf.tables`; the table header/cell contain a double quote and
  a comma so the CSV escaping path is exercised.
- `expected/result.json` — the real stdout of `node samples/quickstart/run.mjs --json`.
- `run.mjs` — `--check` recomputes the extraction and diffs it against the golden file;
  `--json` prints the golden payload; no flag prints a short summary.

Regenerate the sample and golden (after `pnpm build`):

```sh
node scripts/make-sample.mjs
node samples/quickstart/run.mjs --json > samples/quickstart/expected/result.json
node samples/quickstart/run.mjs --check
```

The PDF bytes are deterministic (fixed metadata dates), so regenerating twice yields the
same file. `docs/assets/quickstart.log` and `docs/assets/quickstart.png` are captured from
the real `--check` output; update `screenshots.json` hashes when they change.
